# KUNWON AI Wiki

**건원인터내셔널 건축부문 — AI/LLM 워크플로우 지식 베이스**

---

## 소개

이 위키는 건원인터내셔널 건축부문 설계팀이 실무에서 활용하는 AI·LLM 기반 워크플로우를 체계적으로 정리한 내부 지식 베이스입니다.  
외장 렌더링, 배치도 생성, 2D→3D 변환 등 반복 업무에 사용하는 파이프라인과 프롬프트, 파라미터를 한곳에서 관리합니다.

!!! info "사용 원칙"
    - 승인된 파이프라인과 파라미터만 사용합니다.  
    - 새로운 워크플로우는 반드시 **파라미터 레지스트리**에 등록 후 팀 공유합니다.  
    - 오류 발생 시 **오류 로그**에 즉시 기록합니다.
