# MCP 도구

**Claude Code(및 다른 MCP 호스트)가 대화 중에 직접 호출하는 사내 도구 모음입니다.**

웹앱을 열고 클릭하는 대신, Claude 에게 "이 대지 용도지역 기준 알려줘" 라고 물으면
Claude 가 사내 데이터를 직접 조회해서 답합니다. `kw-ai-hub` 의 카드가 **사람용**이라면
여기는 **Claude(에이전트)용** 진입점입니다.

!!! info "MCP 가 처음이라면"
    MCP(Model Context Protocol)는 Claude 가 외부 도구·데이터에 연결하는 표준 방식입니다.
    설정은 `.mcp.json` 파일에 서버 주소를 한 줄 적는 것으로 끝납니다 — 설치할 것도,
    코드를 받을 것도 없습니다.

!!! warning "왜 어떤 건 인증이 필요하고 어떤 건 아닌가"

    할당량이 나갑니다.** 그래서 비싼 도구만 인증을 붙입니다. (근거: `kunwon-ops` 저장소
    `docs/plan-mcp-gateway.md §7`)

## 빠른 시작 — 건축법규 탐색기

가장 간단한 예시입니다. 프로젝트의 `.mcp.json` 에 아래를 추가하세요
(파일이 없으면 새로 만들면 됩니다):

```json
{
  "mcpServers": {
    "arch-law-graph": {
      "type": "http",
      "url": "https://arch-law-graph-mcp-30350777436.asia-northeast3.run.app/mcp"
    }
  }
}
```

Claude Code 를 재시작(또는 새 세션 시작)하면 끝입니다. 자세한 사용법과 도구 목록은
[건축법규 탐색기 설정 가이드](arch-law-graph.md) 를 참조하세요.
