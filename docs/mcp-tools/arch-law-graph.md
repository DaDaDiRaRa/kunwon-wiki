# 건축법규 탐색기 — MCP 설정

건축 관련 법령 29종(건축법·국토계획법·주차장법·녹색건축법 등)·조례 554·판례를 Claude 가
대화 중에 직접 조회하게 합니다. 원문은 법제처 API 로 실시간 확인됩니다.

!!! success "인증이 필요 없습니다"
    읽기 전용이고 데이터가 전부 공개 법령이라 누구나 바로 씁니다. 토큰도, API 키도 필요 없습니다.

---

## 1. 설정

프로젝트 루트(또는 사용자 설정)의 `.mcp.json` 에 추가합니다:

```json
{
  "mcpServers": {
    "arch-law-graph": {
      "type": "http",
      "url": "https://arch-law-graph-mcp-30350777436.asia-northeast3.run.app/mcp"
    }
  }
}
```

여러 프로젝트에서 항상 쓰고 싶다면 프로젝트별 `.mcp.json` 대신 사용자 전역 설정에
등록하세요(터미널에서 `claude mcp add --transport http arch-law-graph https://arch-law-graph-mcp-30350777436.asia-northeast3.run.app/mcp --scope user`).

## 2. 확인

Claude Code 를 새로 시작한 뒤 `/mcp` 명령으로 `arch-law-graph` 가 연결됐는지 확인합니다.
연결되면 아래처럼 물어보세요:

```
서울시 제1종전용주거지역 건폐율·용적률 기준 알려줘
```

```
건축법 제55조 원문 보여줘
```

## 3. 제공 도구 6개

| 도구 | 하는 일 |
|---|---|
| `search_articles` | 법령·조례·고시·판례 본문 키워드 검색 |
| `get_article` | 조문 원문 단건 + 시행일 + 원문 링크 |
| `lookup_articles` | 조문 배치 조회(최대 50개) |
| `get_citations` | 인용/피인용 관계(판례·해석례 연결 포함) |
| `get_standard` | 기준표 — 국가 기준 vs 도시 조례(용도지역·주차·이격·조경·완화·심의) |
| `get_zoning` | 주소 → 용도지역 확인 |

!!! note "이 도구가 안 하는 것"
    특정 대지의 최종 건폐율·용적률을 계산해 주지 않습니다. "법이 뭐라고 하는가"만 답합니다.
    대지별 산정·판정은 사람의 몫이거나 별도 진단 도구(`arch-law-diagnose`)의 역할입니다.

## 4. 사람용 웹앱과의 관계

같은 데이터를 웹에서 보고 싶다면 [건축법규 탐색기 웹앱](https://arch-law-graph-30350777436.asia-northeast3.run.app) 을 쓰세요.
MCP 서버는 **다른 서비스**로 떠 있어서(백엔드 라이브러리 충돌 회피 목적) 웹앱 상태와 무관하게
독립적으로 동작합니다.

## 5. 문제가 있다면

- `/mcp` 에서 연결 실패로 뜬다 → URL 오타 확인, 사내 네트워크에서 `curl` 로 접속되는지 확인
- 도구를 호출했는데 응답이 없다 → 잠시 후 재시도(Cloud Run 콜드 스타트, 첫 호출은 몇 초 걸릴 수 있음)
- 그래도 안 되면 김정현에게 문의
