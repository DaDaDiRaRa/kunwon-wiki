# 배치도 렌더링 파이프라인

## 개요

배치도 렌더링 파이프라인은 AutoCAD 또는 Rhino에서 작성된 2D 배치도(사이트 플랜)를 입력으로 받아, 조감도 스타일의 컬러 렌더링 이미지로 변환합니다. 기존 Photoshop 수작업과 달리 조경·도로·수공간 등의 재질 표현을 AI가 자동으로 보완하며, 마스터플랜 제안서 및 인허가 보고서용 이미지 제작에 활용됩니다.

---

## 인풋 요구사항

| 항목 | 형식 | 권장 해상도 | 비고 |
|------|------|-------------|------|
| 배치도 원본 | PNG / PDF | 2048×2048 이상 | 레이어 구분 불필요, 흑백 가능 |
| 방위 정보 | 텍스트 또는 이미지 내 표기 | — | 북향 기준 표기 필수 |
| 스타일 참고 이미지 | PNG / JPG | 1024×1024 이상 | 선택 사항, IP-Adapter 사용 시 필요 |
| 스케일 정보 | 텍스트 (예: 1:500) | — | 수목 크기 자동 보정에 활용 |

!!! info "레이어 정리 팁"
    CAD에서 내보낼 때 건물 윤곽, 도로, 조경 영역을 색상으로 구분하면 ControlNet 인식률이 향상됩니다.

---

## 단계별 프로세스

### 1단계 — 배치도 내보내기
1. AutoCAD 또는 Rhino에서 배치도 뷰를 PNG로 내보냅니다.
2. 해상도는 최소 2048×2048, DPI는 150 이상으로 설정합니다.
3. 배경은 흰색, 선 색상은 검정으로 통일합니다.

### 2단계 — 이미지 전처리
1. 배치도를 정방형(1:1 비율)으로 크롭합니다.
2. 필요 시 Photoshop에서 대비를 높여 선을 선명하게 조정합니다.
3. ControlNet용 Segmentation 맵을 생성합니다 (도구: `seg_ofade20k` 전처리기).

### 3단계 — 스타일 설정
1. 원하는 렌더링 스타일을 결정합니다:
    - **사계절 녹지형**: 초록 수목, 자연스러운 조경
    - **도시형 미니멀**: 회색 포장, 가로수 라인
    - **조감도 포토리얼**: 항공사진 질감
2. 해당 스타일의 승인 프롬프트 태그를 [프롬프트 라이브러리](../prompt-library/approved-tags.md)에서 가져옵니다.

### 4단계 — 이미지 생성
1. WebUI **img2img** 탭에서 배치도 이미지를 업로드합니다.
2. [고정 파라미터](#fixed-params)를 적용합니다.
3. 4장 이상 생성 후 최적본을 선택합니다.

### 5단계 — 후처리 및 납품
1. 선택된 이미지에 방위 표시, 스케일 바, 범례를 Photoshop에서 삽입합니다.
2. 파일명 규칙 `YYMMDD_PJT코드_SITE_v00.png`으로 저장합니다.
3. 인허가용 납품 시 PDF로 변환하고 해상도 300 DPI 이상을 확인합니다.

## 고정 파라미터 { #fixed-params }

```yaml
# 배치도 렌더링 고정 파라미터 (변경 금지)
model: "realvisxl_v4.safetensors"
sampler: "Euler a"
steps: 25
cfg_scale: 8.0
seed: 7731042          # → 시드값 레지스트리 참조
denoising_strength: 0.65

controlnet:
  model: "control_v11p_sd15_seg"
  weight: 0.90
  guidance_start: 0.0
  guidance_end: 0.85
  preprocessor: "seg_ofade20k"

image_size:
  width: 2048
  height: 2048
```

---

## 기대 출력물

- **형식**: PNG, 2048×2048 (납품용 PDF 300 DPI)
- **품질 기준**: 건물 윤곽 왜곡 없음, 조경 자연스러움, 도로·보행로 구분 명확
- **납품 수량**: 스타일별 2~4장 생성 후 1장 선택
- **소요 시간**: GPU 환경에서 장당 약 40~70초 (고해상도)

## 일반적인 오류

| 오류 증상 | 원인 | 해결 방법 |
|-----------|------|-----------|
| 건물 블록이 조경으로 채워짐 | Segmentation 맵 오인식 | 건물 영역을 수동으로 마스킹 후 재시도 |
| 수목 크기 비현실적 | 스케일 정보 미입력 | 프롬프트에 `scale 1:500` 명시 |
| 해상도 저하 (블러) | 업스케일러 미사용 | 생성 후 R-ESRGAN 4x로 업스케일 |
| 도로가 녹지로 인식됨 | 선 대비 낮음 | 입력 이미지 대비 조정 후 재시도 |
