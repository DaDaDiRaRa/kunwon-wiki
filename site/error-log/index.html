    오류 로그¶

    AI 파이프라인 운영 중 발생한 오류와 해결 방법을 기록합니다.
    새로운 오류를 발견하면 아래 양식에 따라 추가해 주세요.

    알려진 오류 목록¶

    EXT-001 · 건물 외벽 녹아내림 현상¶

    • 파이프라인: 외장 렌더링
    • 증상: 생성된 이미지에서 건물 외벽이 물처럼 흘러내리거나 형태가 왜곡됨
    • 원인: denoising_strength 값이 0.65 이상으로 설정된 경우
    • 해결 방법: denoising_strength를 0.55로 낮추고 재생성
    • 상태: ✅ 해결됨
    • 최초 보고: 2026-05-20

    EXT-002 · 창호 패턴 반복 오류¶

    • 파이프라인: 외장 렌더링
    • 증상: 창문 패턴이 비정형적으로 반복되거나 간격이 맞지 않음
    • 원인: ControlNet 가중치가 낮아 구조 정보가 충분히 반영되지 않음
    • 해결 방법: ControlNet Weight를 0.85 → 0.95로 높임
    • 상태: ✅ 해결됨
    • 최초 보고: 2026-05-20

    SITE-001 · 건물 블록이 조경으로 채워짐¶

    • 파이프라인: 배치도 렌더링
    • 증상: 건물 위치에 수목이나 잔디가 생성되어 배치도 구조가 틀어짐
    • 원인: Segmentation 전처리기가 건물 블록을 조경 영역으로 오인식
    • 해결 방법: Photoshop에서 건물 영역을 회색으로 마스킹한 후 재입력
    • 상태: 🔄 부분 해결 (근본 원인 조사 중)
    • 최초 보고: 2026-05-20

    SITE-002 · 고해상도 생성 시 VRAM 부족¶

    • 파이프라인: 배치도 렌더링
    • 증상: 2048×2048 이상 해상도에서 CUDA out of memory 오류 발생
    • 원인: GPU VRAM 8GB 이하 환경에서 고해상도 생성 시 메모리 초과
    • 해결 방법 1: 1024×1024로 생성 후 R-ESRGAN 4x 업스케일러 사용
    • 해결 방법 2: WebUI 실행 시 --medvram 또는 --lowvram 플래그 추가
    • 상태: ✅ 해결됨 (업스케일 워크플로우 채택)
    • 최초 보고: 2026-05-20

    APT-001 · 평면도 벽체 단절 생성¶

    • 파이프라인: 아파트 2D→3D
    • 증상: 3D 모델에서 벽체가 여러 조각으로 분리되어 생성됨
    • 원인: 입력 평면도의 선 품질이 낮거나 선이 끊어진 경우
    • 해결 방법: 입력 PNG의 대비를 높이고, 끊어진 선을 Photoshop에서 수동으로 연결 후 재시도
    • 상태: 🧪 조사 중
    • 최초 보고: 2026-05-20
