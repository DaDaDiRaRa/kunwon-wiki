    프롬프트 라이브러리¶

    건원인터내셔널 설계팀이 승인하고 관리하는 프롬프트 태그 모음입니다.
    모든 AI 이미지 생성 작업에서 이 라이브러리의 태그를 우선 사용해야 합니다.

    중요

    차단된 프롬프트 목록의 단어는 어떤 파이프라인에서도 사용할 수 없습니다.
    위반 시 생성된 이미지는 즉시 폐기하고 팀장에게 보고합니다.
