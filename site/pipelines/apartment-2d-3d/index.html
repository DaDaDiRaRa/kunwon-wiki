    아파트 2D → 3D 파이프라인¶

    상태: 테스트 중

    이 파이프라인은 현재 검증 단계입니다. 실제 납품 업무에는 아직 사용하지 마세요. 테스트 결과는 오류 로그에 기록해 주세요.

    개요¶

    아파트 2D→3D 파이프라인은 표준 평면도(단위 세대 또는 층 평면)를 입력으로 받아 3D 매싱 모델을 자동 생성합니다. TripoSR 또는 Shap-E 모델을 활용하여 벽체·개구부·발코니를 자동으로 인식하고, 층고를 기반으로 볼륨을 추출합니다. 초기 매스 검토 및 용적률 시뮬레이션에 활용하는 것을 목표로 합니다.

    인풋 요구사항¶

    항목 형식 권장 해상도 비고
    평면도 이미지 PNG / JPG 1024×1024 이상 벽체 두께 구분 명확해야 함
    층고 정보 텍스트 (예: 2800mm) — 볼륨 추출에 필수
    세대 유형 텍스트 (예: 59㎡ A타입) — 결과물 파일명에 사용
    기준 축척 텍스트 (예: 1:100) — 모델 스케일 보정에 사용

    평면도 준비 팁

    벽체는 검정 실선, 개구부는 흰색, 발코니 영역은 점선으로 구분되어 있을 때 인식률이 가장 높습니다.

    단계별 프로세스¶

    1단계 — 평면도 전처리¶

    1. AutoCAD 또는 Revit에서 단위 세대 평면을 PNG로 내보냅니다.
    2. 배경은 흰색, 벽체 선은 진하게 설정합니다.
    3. plan_preprocessor.py 스크립트를 실행해 벽체 마스크를 추출합니다: 
      python tools/plan_preprocessor.py --input floor_plan.png --output mask.png

    2단계 — 볼륨 생성¶

    1. 추출된 마스크를 TripoSR API에 전송합니다.
    2. 층고 파라미터를 입력합니다 (기본값: 2800mm).
    3. 결과 .glb 파일을 다운로드합니다.

    3단계 — 모델 후처리¶

    1. Blender에서 .glb 파일을 열어 스케일을 검증합니다.
    2. 개구부(창호·출입문) 위치를 수동으로 보정합니다.
    3. 필요 시 발코니 돌출부를 수동으로 추가합니다.

    4단계 — 출력 및 검토¶

    1. .obj, .fbx, 또는 Rhino 호환 형식으로 내보냅니다.
    2. 팀 내부 검토 후 피드백을 오류 로그에 기록합니다.

    고정 파라미터¶

    # 아파트 2D→3D 파이프라인 파라미터 (테스트 단계)
model: "TripoSR-v1.0"
floor_height_mm: 2800
wall_thickness_detection: "auto"
opening_detection: true
balcony_extrusion_mm: 1500
output_format: "glb"
mesh_resolution: "medium"   # low / medium / high

seed: 1190283              # → 시드값 레지스트리 참조

    기대 출력물¶

    • 형식: .glb (Blender 호환), .obj (범용), .3dm (Rhino)
    • 품질 기준: 벽체 연속성 유지, 층고 오차 ±50mm 이내, 개구부 위치 근사 일치
    • 납품 수량: 세대 유형별 1개 모델
    • 소요 시간: CPU 환경 약 3~5분 / GPU 환경 약 40~60초

    일반적인 오류¶

    오류 증상 원인 해결 방법
    벽체가 단절되어 생성됨 평면도 선 품질 낮음 입력 이미지 선명도 향상 후 재시도
    층고가 맞지 않음 파라미터 미입력 floor_height_mm 값 확인
    발코니 누락 점선 인식 실패 발코니 영역을 실선으로 재작성
    .glb 파일 열리지 않음 Blender 버전 불일치 Blender 3.6 이상 사용
    모델 스케일 틀어짐 축척 정보 미입력 프롬프트에 scale 1:100 명시
